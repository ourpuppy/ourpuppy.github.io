본 방침은 OurPuppy(이하 "회사")가 배포하는 모바일 게임 Sniper Front 1944(스나이퍼 프론트 1944)(이하 "게임")가 어떤 정보를 수집하고, 어떻게 이용하며, 이용자가 어떤 선택을 할 수 있는지 설명합니다. 게임은 광고와 선택적 인앱 결제로 운영되는 무료 싱글플레이 저격 게임입니다.

1. 요약

  • 게임은 계정이 필요 없습니다. 이름, 이메일, 전화번호, 연락처, 사진, 정밀 위치를 수집하지 않습니다.
  • 게임 진행 데이터(미션·별·골드·무기 강화·설정)는 이용자의 기기에만 저장됩니다.
  • 광고 파트너(Unity LevelPlay/ironSource)는 광고 표시와 측정을 위해 광고 ID와 기술적 기기 정보를 수집할 수 있습니다.
  • 게임 분석 서비스(GameAnalytics)는 게임 개선을 위해 익명 플레이 통계(세션, 미션 진행, 광고·구매 이벤트)를 수집합니다. 이용자가 거부하면 전송하지 않습니다.
  • 인앱 결제는 Google Play가 처리하며 회사는 결제 정보를 볼 수 없습니다.
  • 첫 실행 때 동의 여부를 묻고, 메뉴의 개인정보 버튼에서 언제든 바꿀 수 있습니다. 삭제 방법은 데이터 삭제 안내를 참고하세요.

4. 광고·분석과 이용자의 선택

게임을 처음 실행하면 동의 팝업이 뜹니다.

  • 동의: 광고 ID를 이용한 맞춤 광고가 표시되고, 익명 플레이 통계가 GameAnalytics로 전송됩니다.
  • 거부: 광고는 계속 표시되지만 광고 파트너에게 "미동의" 신호를 보내 맞춤 광고에 데이터가 사용되지 않도록 하고, 게임 분석 전송은 꺼집니다. 게임 기능에는 차이가 없습니다.

선택은 언제든 게임 메뉴의 개인정보 버튼에서 바꿀 수 있습니다. Android 설정 → Google → 광고(또는 설정 → 개인정보 보호 → 광고)에서 광고 ID를 재설정하거나 삭제할 수도 있습니다. "광고 제거" 상품을 구매하면 전면 광고가 꺼지며, 보상형 광고는 이용자가 직접 선택할 때만 표시됩니다.

5. 보유 기간

로컬 게임 데이터는 게임을 삭제하거나 저장공간을 지울 때까지 기기에 보관됩니다. 광고 파트너는 자체 정책에 따라 데이터를 보관합니다(광고 측정 목적으로 통상 최대 13개월). GameAnalytics는 집계 통계를 위해 이벤트 데이터를 보관하며 개별 이용자를 식별하는 데 쓰지 않습니다. 회사는 이용자의 개인정보를 저장하는 서버를 운영하지 않습니다.

6. 데이터 삭제

삭제 요청은 언제든 가능합니다. 게임에는 계정이 없으므로 절차는 다음과 같습니다.

  1. 게임 안에서: 메뉴 → 개인정보 → 내 기기 데이터 삭제. 진행 기록이 지워지고 분석 전송이 꺼집니다.
  2. 로컬 게임 데이터: 게임을 삭제하거나 Android 설정 → 앱 → Sniper Front 1944 → 저장공간 → 데이터 삭제.
  3. 광고 데이터: Android 설정 → Google → 광고에서 광고 ID를 재설정 또는 삭제합니다.
