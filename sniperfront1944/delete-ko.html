데이터 삭제 요청 안내

앱: Sniper Front 1944 (스나이퍼 프론트 1944) · 개발자: OurPuppy · 문의: ourpuppy8373@gmail.com · 패키지명: com.ourpuppy.sniperfront

Sniper Front 1944는 계정을 사용하지 않습니다. 삭제할 계정이 없으며, 회사는 이용자의 개인정보를 저장하는 서버를 운영하지 않습니다. 존재하는 데이터는 (1) 기기에 저장된 게임 진행 데이터, (2) 광고 파트너가 보유한 광고 데이터, (3) 게임 분석 서비스가 보유한 익명 플레이 통계이며, 아래 방법으로 모두 삭제하거나 전송을 중단할 수 있습니다.

1. 게임 안에서 바로 삭제 (가장 간단)

메인 메뉴 → 개인정보 버튼 → 내 기기 데이터 삭제 → 확인

미션 진행·별·골드·해금 무기·설정이 기기에서 지워지고, 분석 전송과 맞춤 광고 동의가 "거부"로 바뀝니다. Google Play로 구매한 상품(예: "광고 제거")은 상점의 구매 복원으로 다시 받을 수 있습니다.

2. 기기에 저장된 게임 데이터 삭제

  • 게임을 삭제하거나,
  • Android 설정 → 앱 → Sniper Front 1944 → 저장공간 및 캐시 → 저장공간 지우기를 실행합니다.

3. 광고 데이터 삭제 또는 재설정

  • Android 설정 → Google → 광고(기기에 따라 설정 → 개인정보 보호 → 광고)를 엽니다.
  • "광고 ID 삭제" 또는 "광고 ID 재설정"을 누릅니다.

광고 파트너(Unity LevelPlay/ironSource, Unity Ads)는 광고 ID로만 기기를 식별합니다. 광고 ID를 삭제·재설정하면 이전에 수집된 광고 데이터와 기기의 연결이 끊어집니다. Unity에 직접 요청할 수도 있습니다: Unity 개인정보처리방침.

4. 게임 분석 데이터

GameAnalytics는 임의 생성 ID 기준의 익명 통계만 보유합니다. 게임 안 개인정보에서 "거부"를 선택하면 이후 전송이 중단됩니다. 이미 전송된 데이터의 삭제는 아래 이메일로 요청하시면 회사가 GameAnalytics에 전달합니다(GameAnalytics 개인정보처리방침).
