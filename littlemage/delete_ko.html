앱

개발사
OurPuppy — ourpuppy8373@gmail.com
계정
앱에서 계정을 만들 수 없습니다(회원가입·로그인 없음). 진행 데이터는 무작위 플레이어 ID와 함께 기기에만 저장되므로, 「계정 삭제」는 아래의 데이터 삭제로 대신합니다.

방법 1. 게임 안에서 바로 삭제

  1. 마법사 키우기를 실행하고 화면 오른쪽 위 설정(톱니바퀴)을 누릅니다.
  2. 내 데이터 삭제 → 삭제를 누릅니다.
  3. 기기 안의 게임 데이터가 즉시 모두 지워지고 분석 전송이 멈춥니다. 완료 창에 플레이어 ID와 협력사 기록 삭제용 삭제 요청 메일 보내기 버튼(방법 2), 데이터 삭제 안내 보기 버튼이 나옵니다.
  4. 확인을 누르면 게임이 처음 화면(약관 동의)부터 다시 시작합니다.

방법 2. 메일로 삭제 요청 (광고·분석 협력사 기록 포함)

  1. ourpuppy8373@gmail.com으로 제목 [마법사 키우기] 데이터 삭제 요청 메일을 보냅니다. 게임 안 「삭제 요청 메일 보내기」 버튼을 누르면 받는 사람·제목·플레이어 ID·기기 모델이 자동으로 채워집니다.
  2. 플레이어 ID(설정 화면 아래 또는 방법 1의 완료 창)와 기기 모델을 적어 주세요. 앱을 이미 지웠다면 기기 모델과 대략적인 이용 기간을 적어 주세요.
  3. 회사가 접수를 회신하고, 10일 이내에 협력사(GameAnalytics, Unity LevelPlay/ironSource)에 플레이어 ID와 연결된 기록의 삭제를 요청한 뒤, 처리 결과를 30일 이내에 메일로 알려 드립니다.
