계정
회원 계정·로그인·회사 서버가 없습니다. 진행 데이터는 무작위 플레이어 ID와 함께 기기에만 저장되므로, 「계정 삭제」는 아래의 데이터 삭제로 대신합니다.

방법 1. 게임 안에서 바로 삭제

  1. 게임을 실행하고 첫 화면 오른쪽 위 설정을 누릅니다.
  2. 내 데이터 삭제 → 확인 창에서 확인을 누릅니다.
  3. 기기 안의 게임 데이터(엔딩·업적·모은 그림, 오늘 최고 기록·연속 탈출, 난이도, 설정(소리·진동·감도·왼손 모드·언어·알림), 동의 상태, 구매 상태, 튜토리얼 완료 여부, 광고 표시 횟수, 플레이어 ID)가 즉시 모두 지워지고 분석 전송이 멈춥니다. 게임은 처음 화면으로 돌아갑니다.

방법 2. 메일로 삭제 요청 (광고·분석 협력사 기록 포함)

  1. ourpuppy8373@gmail.com으로 제목 [층간소음] 데이터 삭제 요청 메일을 보냅니다.
  2. 기기 모델과 대략적인 이용 기간을 적어 주세요. 앱을 이미 지웠어도 됩니다.
  3. 회사가 접수를 회신하고, 30일 이내에 협력사(GameAnalytics, Unity LevelPlay/ironSource)에 기기·플레이어 ID와 연결된 기록 삭제를 요청한 뒤 결과를 메일로 알려 드립니다.
