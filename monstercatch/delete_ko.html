앱
몬스터 잡아 키우기: 포획 서바이벌 (Google Play, 패키지명 com.ourpuppy.monstercatch)
개발사
OurPuppy — ourpuppy8373@gmail.com
계정
회원 계정·로그인이 없습니다. 진행 데이터는 무작위 플레이어 ID와 함께 기기에 저장되므로, 「계정 삭제」는 아래의 데이터 삭제로 대신합니다.

방법 1. 게임 안에서 바로 삭제

  1. 몬스터 잡아 키우기를 실행하고 로비 오른쪽 아래 설정(톱니바퀴)을 누릅니다.
  2. 내 데이터 삭제 → 삭제를 누릅니다.
  3. 기기 안의 게임 데이터가 즉시 모두 지워지고 분석 전송이 멈춥니다. 확인 창에 플레이어 ID와 협력사 기록 삭제용 메일로 요청 버튼(방법 2)이 나옵니다.

방법 2. 메일로 삭제 요청 (광고·분석 협력사 기록 포함)

  1. ourpuppy8373@gmail.com으로 제목 [몬스터 잡아 키우기] 데이터 삭제 요청 메일을 보냅니다.
  2. 플레이어 ID(설정 화면 또는 방법 1의 확인 창)와 기기 모델을 적어 주세요. 앱을 이미 지웠다면 기기 모델과 대략적인 이용 기간을 적어 주세요.
  3. 회사가 접수를 회신하고, 30일 이내에 협력사(GameAnalytics, Unity LevelPlay/ironSource)에 플레이어 ID와 연결된 기록 삭제를 요청한 뒤 결과를 메일로 알려 드립니다.

삭제되는 데이터, 남는 데이터와 보관 기간

데이터처리시점 / 보관 기간
기기 안 게임 데이터: 진행도, 도감, 재화, 옷, 미션, 목장, 기록, 설정, 동의 기록, 플레이어 ID삭제즉시(방법 1) 또는 앱 삭제 시
GameAnalytics 분석 기록 (플레이어 ID 기준)회사 요청으로 삭제요청 후 30일 이내
광고 기록: Unity LevelPlay/ironSource 및 연동 광고 네트워크 (광고 ID·플레이어 ID 기준)삭제 요청. Android 설정 > Google > 광고에서 광고 ID 삭제·초기화도 가능요청 후 30일 이내

「광고 제거」처럼 한 번 사면 유지되는 구매는 Google Play에 기록되어, 데이터를 삭제한 뒤에도 같은 Google 계정으로 복원됩니다. 이미 받은 젬 등 재화와 상자에서 얻은 몬스터는 삭제 후 복구되지 않습니다.
