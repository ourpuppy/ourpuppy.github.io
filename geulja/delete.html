계정
회원 계정·로그인이 없고 회사 서버도 없습니다. 게임 기록은 무작위 플레이어 ID와 함께 기기 안에만 저장되므로, 「계정 삭제」는 아래의 데이터 삭제로 대신합니다.

방법 1. 게임 안에서 바로 지우기

  1. 게임을 실행하고 홈 오른쪽 위 설정(톱니바퀴)을 누릅니다.
  2. 맨 아래 기록 지우기 → 지우기를 누릅니다.
  3. 기기 안의 게임 기록(푼 판, 점수, 별, 달력 도장, 연속 일수, 설정)과 동의 기록이 즉시 지워지고 분석 전송이 멈춥니다. 「광고 제거」 구매는 유지됩니다.

앱을 삭제(제거)하면 기기 안의 게임 기록과 플레이어 ID가 모두 함께 지워집니다. 회사 서버에 보관되는 데이터는 없습니다.

방법 2. 메일로 삭제 요청 (광고·분석 협력사 기록 포함)

  1. 게임 설정 > 문의를 누르면 플레이어 ID·기기 모델·앱 버전이 들어간 메일이 열립니다. 제목을 [글자 잇기] 데이터 삭제 요청으로 바꾸고 보내 주세요. 직접 쓰실 때는 ourpuppy8373@gmail.com으로 보내시고, 설정 화면 맨 아래의 플레이어 ID를 적어 주세요.
  2. 앱을 이미 지워 플레이어 ID를 모르면 기기 모델과 대략적인 이용 기간을 적어 주세요.
  3. 회사가 접수를 회신하고, 30일 이내에 협력사(GameAnalytics, Unity LevelPlay/ironSource)에 플레이어 ID와 연결된 기록 삭제를 요청한 뒤 결과를 메일로 알려 드립니다.
